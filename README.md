# 🐼 Operation: Cheer Up Matko ❤️

An interactive, animated, and heartfelt apology website built with endless love for **Aishwarya** (affectionately called **Matko**).

---

## ✨ Features

- 🐼 **Chubby Panda Hero & Anger-O-Meter**: Interactive mood tracker transitioning from *100% Pouty / Silent Treatment* to *0% Soft & Loved*.
- 🫓 **Chole Kulche Mini-Game**: Feed Matko her ultimate comfort food with bite animations and cute munching sound effects to deflate her anger.
- 💌 **Heartfelt Letter to Aishwarya**: A sincere, vulnerable letter taking 100% accountability for arguing and not giving enough time, tucked inside an unfolding wax-seal envelope.
- 📸 **Polaroid & Video Reels Gallery**: Featuring real photos and video clips of Matko in vintage frames with play/pause controls.
- 🏃‍♂️ **The Legendary Runaway "NO" Button**: The elusive "NO" button that dodges the cursor/finger across the screen with funny voice bubbles, while the "YES" button expands invitingly.
- 🎉 **Love Overload & Confetti Burst**: Full-screen romantic confetti explosion upon clicking "YES".
- 🎟️ **Matko's VIP Love Coupons**: 4 claimable, non-expiring digital coupons (Unlimited Chole Kulche Date, 100% Attentive Listening Pass, Giant Panda Hug, Matko is Always Right Card).
- 🎵 **Floating Romantic Lo-Fi Music Player**: Ambient romantic chord player with spinning vinyl disk.

---

## 🛠️ Tech Stack

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4**
- **Lucide React** (Cute icons)
- **Canvas Confetti**
- **Web Audio API** (Zero-latency sound effects & warm romantic synth pads)

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
